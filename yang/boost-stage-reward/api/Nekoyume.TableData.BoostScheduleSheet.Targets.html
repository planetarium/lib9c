StageItemReward

Material item rewards of an adventure stage clear (HackAndSlash, HackAndSlashSweep). target_id is the StageSheet stage id, so 1~300 covers stages 1 through 300. Event dungeon stages are not covered.

Applied per clear to the count of each distinct item after the items are drawn, so the random draws are the same as without the row: MUL 2 grants exactly twice each drawn item and ADD 1 one more of each. See StageSimulator.ApplyItemRewardBoost.

Boosted items are ordinary rewards everywhere else too: they count toward collect quest progress, and a circle stays tradable.

Rounding is per item id per clear, so a MUL between 1 and 2 has no effect on an item drawn once in a clear — which is how most stages drop. Prefer ADD or an integer MUL for items; StageFavReward amounts are large, so a fractional MUL scales them as expected. 

public const string StageItemReward = "STAGE_ITEM_REWARD"
