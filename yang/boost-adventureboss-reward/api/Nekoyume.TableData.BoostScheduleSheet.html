Class BoostScheduleSheet

Namespace

Schedules a temporary adjustment of a game value — a reward amount, a cost, a guarantee count — for a block range, so that an event can be run with patch_table_sheet instead of rewriting the value's own sheet and patching it back afterwards.

Columns: id, target, target_id, op, value, start_block, end_block. A _memo column, like any _ prefixed column, is dropped on load and may be used for notes.

target_id is a single id (50), an inclusive range (1~50) or * for every id. ~ rather than - keeps a spreadsheet from reading a range as a date on its way to the CSV.

target names what is adjusted and is matched as a plain string by the call site that owns it, so the sheet itself never needs to know which targets exist. A node that predates a target simply finds no match for it instead of failing to read the sheet. BoostScheduleSheet.Targets lists the targets this version applies.

A row applies in [start_block, end_block). When several rows match, the one with the lowest id wins; rows are never combined, so overlapping rows cannot stack into a larger adjustment than any single row declares.

Reading is total: a row that does not parse is kept but marked invalid and never matches, so a typo fails toward "no adjustment" instead of aborting every action that reads the sheet. ValidateCsv(string) rejects such a row at patch time so it should not reach the chain in the first place.

Callers must tolerate the sheet being absent — it reaches an existing chain only by patch_table_sheet. Absence means no adjustment, which is also what keeps re-evaluation of pre-patch blocks identical.

Remarks

Whether a target is applied by any running code is deliberately not checked here: the set of targets grows with releases, and a patch must not be accepted by one node version and rejected by another. Compare against Applied off-chain.

Exceptions

SheetRowValidateException

The header does not match ColumnNames, or a row has an unusable or duplicated id, an empty target, an unparsable cell, a value out of range for its operation, or a block range that is empty.
