Applies the SummonRuneEnhancementCrystalCost and SummonRuneEnhancementRuneStoneCost rows active at blockIndex to the cost of one try that reaches targetLevel.

public static RuneCostSheet.RuneCostData ApplyEnhancementCostBoost(RuneCostSheet.RuneCostData cost, int runeId, int targetLevel, RuneEnhancementCostBoost? boost, long blockIndex)

Returns

RuneCostSheet.RuneCostData

cost itself when no row applies; otherwise a copy whose crystal and rune stone quantities are adjusted by ApplyEnhancementCostBoostQuantity(Row?, int). NCG quantity and success rate are always copied unchanged.

Remarks

Callers showing a cost — or a maximum try count — should pass every per-level cost through this, with the boost from ResolveEnhancementCostBoost(BoostScheduleSheet?, int, long, Func<RuneSummonSheet?>), so that they agree with RuneEnhancement.

ApplyEnhancementCostBoostQuantity(Row?, int)

Applies one BoostScheduleSheet row to one enhancement cost quantity.

public static int ApplyEnhancementCostBoostQuantity(BoostScheduleSheet.Row? boost, int baseCost)

Parameters

boost BoostScheduleSheet.Row

The row to apply, or null for none.

baseCost int

The sheet's quantity.

Returns

int

The adjusted quantity, kept within [1, baseCost] when baseCost is positive. A non-positive baseCost is returned unchanged.

Remarks

Discount only: a row can never raise a cost. Raising one is not an event anyone has asked for, and it would let a mistyped row push the per-try sum in TryEnhancement(int, Row, IRandom, int, out LevelUpResult, RuneEnhancementCostBoost?, long) past MaxValue, where it wraps negative and the cost is skipped instead of charged.

At least 1: rounding down a small cost (4 stones × 0.2 = 0.8) would otherwise make the try free, turning a discount into a giveaway that the row never declared. A free enhancement has to be configured in RuneCostSheet itself. A cost the sheet already sets to 0 stays 0, so a boost never creates a cost either.

ResolveEnhancementCostBoost(BoostScheduleSheet?, int, long, Func<RuneSummonSheet?>)

Decides whether a rune's enhancement cost may be adjusted at all, and returns what to pass to TryEnhancement(int, Row, IRandom, int, out LevelUpResult, RuneEnhancementCostBoost?, long) and ApplyEnhancementCostBoost(RuneCostData, int, int, RuneEnhancementCostBoost?, long).

public static RuneEnhancementCostBoost? ResolveEnhancementCostBoost(BoostScheduleSheet? boostScheduleSheet, int runeId, long blockIndex, Func<RuneSummonSheet?> getRuneSummonSheet)

Parameters

boostScheduleSheet BoostScheduleSheet

The patched BoostScheduleSheet, or null when the chain has none.

runeId int

The rune being enhanced.

blockIndex long

The block being evaluated.

getRuneSummonSheet Func<RuneSummonSheet>

Loads the RuneSummonSheet, returning null when it is absent or unreadable. Called only when an enhancement cost row is active at blockIndex, so that evaluation without one reads no extra state.

Returns

RuneEnhancementCostBoost

A RuneEnhancementCostBoost over boostScheduleSheet when a SummonRuneEnhancementCrystalCost or SummonRuneEnhancementRuneStoneCost row is active at blockIndex and runeId is a recipe id of any RuneSummonSheet group; otherwise null, meaning no adjustment.

Remarks

The summon pool is derived from the sheet rather than listed, so the adjustment follows later changes to it. A recipe counts whatever its ratio and whether or not its group is currently sold. A missing RuneSummonSheet means no rune is summonable, never an error.

TryEnhancement(int, Row, IRandom, int, out LevelUpResult, RuneEnhancementCostBoost?, long)

Simulates tryCount enhancement tries from startRuneLevel, summing the cost of every try and drawing one random number per try for its success.

public static bool TryEnhancement(int startRuneLevel, RuneCostSheet.Row costRow, IRandom random, int tryCount, out RuneEnhancement.LevelUpResult levelUpResult, RuneEnhancementCostBoost? boost = null, long blockIndex = 0)

Parameters

startRuneLevel int

The rune level before the first try.

costRow RuneCostSheet.Row

The rune's cost row.

random IRandom

The random source; one draw per try.

tryCount int

The number of tries.

levelUpResult RuneEnhancement.LevelUpResult

The level-ups and the summed cost.

boost RuneEnhancementCostBoost

What ResolveEnhancementCostBoost(BoostScheduleSheet?, int, long, Func<RuneSummonSheet?>) returned for this rune, or null for none. Adjusts each try's crystal and rune stone cost; see ApplyEnhancementCostBoost(RuneCostData, int, int, RuneEnhancementCostBoost?, long). Ignored, not rejected, when it was resolved for a rune other than costRow's, so a preview holding on to a stale boost shows the undiscounted cost the chain would charge.

The block being evaluated, against which boost rows are matched. Ignored when boost is null.
