Remarks

The validated sheets are read leniently at runtime: a row that does not parse is kept but never matches, so a malformed patch would otherwise land and silently misconfigure the game with nothing reporting it. The world-open sheets are also read by every HackAndSlash, where an empty CSV would make Set(string, bool) throw and fail all of them, so an empty or whitespace-only CSV is rejected for them too.
