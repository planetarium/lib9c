ConfirmSatisfiedAfterPatch(IWorld, string, long)

Confirms every pending opening whose conditions are already met, after tableName was patched. A table patch can lower a threshold below a counter that no longer moves often (a rarely cleared stage, a rarely crafted recipe); confirming here means such an opening does not wait for the next matching play. Only a WorldOpenSheet or WorldOpenConditionSheet patch triggers it; any other sheet, or absent world-open sheets, writes nothing.

Tick(IWorld, GlobalCounterType, int, long, int, long)

Adds delta to every counter of type covering target that a pending opening references, then confirms the openings whose conditions are now met. Writes nothing when no sheet defines such a counter, so ordinary actions cost nothing extra.

Remarks

Matching counters are processed one at a time in ascending id (not CSV order), and whether an opening is still pending is re-read for each counter. So if counter A's tick confirms opening X, a later counter B that only X references is not written in the same call: X is no longer pending by then. A counter shared by several pending openings is written once per call, not once per opening.
