TryGetAppliedBlock(IWorldState, WorldOpenSheet, Row, out long)

The first block at which IsApplied(IWorldState, WorldOpenSheet, Row, long) becomes true for open, given the current state: the latest over the prerequisite chain of each row's own effective block (its fallback when unconfirmed, otherwise min(fallback, max(confirmed + delay, min))). Confirming an opening later can only bring this block earlier, never later.
