NextLong(IRandom, long, long)

Returns a value in [minValue, maxValue), like Next(int, int) but for 64-bit bounds.

public static long NextLong(this IRandom random, long minValue, long maxValue)

Parameters

random IRandom

The random source.

minValue long

The inclusive lower bound.

maxValue long

The exclusive upper bound.

Returns

long

The drawn value.

Remarks

When both bounds fit in int, this calls Next(int, int) and nothing else, so sheet values that already fit draw exactly what they drew before the sheet columns became long. Only a wider range reads 8 bytes from NextBytes(byte[]); its modulo bias is at most range / 2^64, negligible for sheet-sized ranges.

Exceptions

ArgumentOutOfRangeException

minValue is greater than maxValue.
