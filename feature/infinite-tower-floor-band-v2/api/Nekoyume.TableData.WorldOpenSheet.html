Defines when each hard world segment opens: up to which stage, which opening it follows, and the block window (earliest, fallback, activation delay) around it. The conditions that open it are in WorldOpenConditionSheet.

Columns: id, world_id, stage_end, prerequisite_open_id (empty for none), min_block_index, fallback_block_index, effective_delay_block.

Set(IReadOnlyList<string>) does not validate across rows, so a test can build an invalid sheet directly; ValidateCsv(string) does, at patch time.

A patch cannot change what an id means once recorded; see WorldOpenIdentity.

Remarks

Exceptions

SheetRowValidateException

The header does not match ColumnNames; an id is not a positive unique integer; a cell does not parse; fallback_block_index is not positive; min_block_index is negative or greater than the fallback; effective_delay_block is negative or greater than the fallback; a prerequisite is unknown, refers to itself or is part of a cycle; stage_end does not increase along a prerequisite; or a row other than the one with the lowest stage_end does not take the row just below it (by stage_end, across all worlds) as its prerequisite.
