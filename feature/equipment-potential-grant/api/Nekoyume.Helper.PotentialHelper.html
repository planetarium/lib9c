Roll(Equipment, int, EquipmentPotentialOptionPoolSheet, IRandom)

Rolls potential options for the given equipment, filling slotCount slots. Each slot is a weighted-random pick from the option pool restricted to the equipment's sub type, with a value rolled uniformly within the selected option's inclusive [ValueMin, ValueMax] range. The result is fully deterministic given random.
