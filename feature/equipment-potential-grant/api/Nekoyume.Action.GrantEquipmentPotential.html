Class GrantEquipmentPotential

Namespace
Nekoyume.Action
Assembly
Lib9c.dll

Grants (rolls) latent "potential" options onto an existing equipment owned by the avatar. The number of slots is determined by the equipment's grade and a material cost is consumed, both driven by EquipmentPotentialGradeSheet; the rolled options come from EquipmentPotentialOptionPoolSheet. This is the granting phase only — the rolled options are stored on the equipment as (option id, value) pairs, and their interpretation into stat effects is handled elsewhere.

Re-rolling is intentional: running this action again on the same equipment overwrites the existing potential with a fresh roll and charges the cost again. It does not accumulate slots.
