The conditions that open a WorldOpenSheet opening: within one condition_group every counter must reach its threshold, and any one group being satisfied opens it (AND within a group, OR across groups).

Columns: open_id, condition_group, counter_id, threshold. Cross-sheet references (open_id, counter_id) are not validated here.

open_id is not unique, so a row's key is a synthetic sequential number assigned in the order rows are added (CSV order, starting at 1). Look rows up with GroupsOf(int) or OpenIdsReferencing(int) rather than by key.

A patch cannot change what an id means once recorded; see WorldOpenIdentity.
